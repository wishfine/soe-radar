# 全国校招覆盖完整性

确认日期：2026-10-23（Asia/Shanghai）。用户明确：本项目重点是“全”，全国国央企校招优先，每年持续使用。本要求与跨年度要求共同约束后续实施。本文是产品约束和待实施计划，不表示以下能力均已完成。

## 产品目标与覆盖范围

优先解决漏掉企业、招聘活动、子公司和独立批次的问题。不能把十个起步入口、若干页面可读或网页功能完成当作全国覆盖完成。日期不明确的真实校招也必须保留为可查询线索，不能为提高已核验比例丢弃。

覆盖底册分别维护国务院国资委监管央企、财政部等主管的中央企业及中央金融/文化企业、地方国企和有官方关系证据的所属单位。地方国企从省级名录继续扩展到地市及区县，不以省属集团替代全部地方国企。集团统一招聘与所属单位独立招聘都需要发现，提前批、秋招、春招、补录及重开分别跟踪。

底册来自官方名录并保存版本、获取时间、原始证据和适用范围。主管口径不同的名单不能当作同一份全国全集；没有完整底册时分母标记未知，不展示“全国覆盖率 100%”。重组、更名、划入划出按版本更新，不永久硬编码企业总数。

官方名录起点：[国务院国资委央企名录](https://wap.sasac.gov.cn/n2588045/n27271785/n27271792/index.html)、[财政部履行出资人职责的中央企业名录](https://zcgls.mof.gov.cn/zhuantilanmu/czblz/202108/t20210817_3745862.htm)。后者另列中央文化企业并指向中央金融企业名录，不能仅以国资委名单代表所有国央企。

## 发现、采集与缺口

每家企业可以关联多个长期招聘入口、年度专题、所属单位入口及补充发现渠道。官方招聘入口为持续监测主线；国资/就业平台、学校就业网、飞书 CSV 及可选搜索作为补漏线索，分别保存来源。线索身份与截止证据核实后再进入已核验列表。

按“企业 → 入口 → 活动 → 批次/岗位 → 截止证据”检查覆盖，不能用抓到集团一篇公告代替子公司已覆盖。搜索结果、历史公告或一份可读取的名录也不能计为当届招聘监测成功。

必须区分：未建档、入口待查、入口已配置但未检查、访问受阻、列表部分采集、近期巡查未发现当届公告、已发现真实校招、截止待补证、已核验。访问失败与未发现公告都不能解释为企业不招聘；两者均进入可追踪的补采队列。

网页、文字 PDF、图片海报、附件表格应有不同采集/识别路径。OCR 和模型解析仍受免费与费用配置约束；暂不能读取的附件保留原件、链接及原因，排队或人工转录，不静默跳过。

## 网络路径

分别支持来源级默认网络、无环境代理、显式代理策略，并记录每次尝试的路径与结果；模型网络配置和国内招聘采集配置分开。诊断仅报告代理是否配置及脱敏错误，不输出节点、订阅、凭证。保留域名、私网和 TLS 校验。

2026-10-23 本机检查：Clash 处于 global 模式且 TUN 开启；未配置 HTTP(S) 代理环境变量，macOS 系统 HTTP(S)/SOCKS 代理开关关闭。针对三处官方名录入口，无环境代理与显式本地 Clash 代理尝试均连接失败。因此不能认定是来源网站失效，也不能声称已经绕开梯子。应用里的无环境代理仍可能经过系统 TUN；修改全局代理/TUN/分流规则由用户控制，项目不擅自修改。

## 后续实施顺序与验收

1. 网络诊断与路径配置：扩展 `Settings` / `SourceSpec`、`Fetcher` 及 `doctor`，增加来源级路由和脱敏尝试记录。模拟验证不同路径、失败切换、重定向域名限制；真实检查当前受阻入口。不把 HTTP 200 动态壳计为成功。
2. 覆盖底册：新增独立名录导入/刷新模块，记录官方版本和原始证据；与现有 `Employer`、名录关系及来源配置关联。名单减少保留历史，不删除企业及招聘；入口未找到也保留企业缺口。测试去重、版本变化和未知分母。
3. 覆盖工作台：新增企业/地区/集团覆盖查询和缺口列表。展示名单中企业数、有监测入口数、近期检查成功数、真实当届校招数和截止待补证数；各分母与时效显式说明。现有 4/10 只能称已配置来源的可用情况，不能称全国覆盖率。
4. 按缺口扩源与交叉补漏：优先补齐央企集团及中央金融等未接入范围，同时登记全国地方名录；按地方、子公司和独立入口逐批推进。为每批交付列出企业名单、入口、实际取得内容及未解决原因。持续维护未知截止、图片/表格附件和延期链路。

“全”的验收不能只数链接：需与独立参考清单核对当届活动遗漏并报告召回、检查新公告的发现延迟、列出所有已知未覆盖项。未知截止不是缺失招聘，失败源不是无招聘。原先 150 份公告日期准确率及七天观察继续验证解析和稳定性，不能替代企业/活动覆盖验收。

当前状态：现有程序具备十源配置和四源本轮可用的起步链路，尚未实现全国底册与覆盖工作台，不能宣称满足“全”。后续优先推进上述主线，界面润色不替代补齐覆盖。
