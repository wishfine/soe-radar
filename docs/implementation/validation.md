# 首版本地验证记录

实施开始于 2026-10-22，收尾于 2026-10-23（Asia/Shanghai）。这是短时实现和连通性记录，尚未完成长期与人工真值验收。

本轮四阶段修复与最新实测见 [修复记录](2026-10-23-review-fixes.md)。以下为首版交付时的历史记录；来源当前状态以工作台为准。

## 已验证的软件链路

- Python 3.12、uv 锁定安装；在独立的新目录执行 `uv sync --frozen`、`init`、`doctor` 成功，无模型 Key 也能初始化。
- 84 项自动化测试通过，包含日期语义与证据、缺年份与跨年、24 点、多届与旧 URL、延期和提前关闭、岗位范围、模型预算与暂停、重复同步、分页续跑、任务恢复、备份恢复、网页 API、CSV 与 ICS。
- Ruff 检查、格式检查、JavaScript 语法检查通过；wheel 和源码分发包构建成功。
- 从 wheel 解包后在临时目录再次验证初始化、迁移、首页、静态资源和空数据库 API，均成功。
- Alembic 迁移与当前 ORM 结构一致。规则升级会重新校验旧文档，并保留多次日期纠正的审计记录。
- 实际浏览器打开工作台，检查历年归档、截止原文、变更历史和关注状态更新；测试关注状态已经还原。
- GitHub Actions 配置使用固定样例与模拟供应商。本地验证不代表远端 CI 结果，远端状态以 GitHub Actions 运行记录为准。

测试有一条上游 Starlette/TestClient 的 httpx 弃用提示，不影响当前测试结果。

## 模型验证

- OpenCode 模型目录曾可读取，但匿名生成请求返回 HTTP 403。本机没有配置用户的 OpenCode Key，因此没有把免费 API 生成标记为可用。配置有效 Key 后运行 `doctor --model` 再验证。
- Chat Completions 和 Responses 协议通过模拟供应商测试，包含无 Key、401/402/403/404/429、无效 JSON、日调用上限、免费模型名单及付费预算不足。
- 可选本机 Codex CLI 使用 `gpt-6-luna` 成功处理一份真实的湖北交投校招公告，将“2026 年 10 月 16 日开启网申、截止请关注公众号”返回为 `unannounced`，没有误填 10 月 16 日。独立校验要求该记录继续待核验。
- 本机入口的这一次真实样例不构成准确率验收。仓库默认配置中的本机模式、收费 API 均保持关闭；默认付费预算为零，未启用收费回退。

本机证据位于被 Git 忽略的 `data/`，包含真实同步结果、模型检查结果、快照、附件和数据库；软件仓库不附带个人数据库或凭证。

## 未完成的验收

1. **150 份人工标注公告**尚未完成。已生成待标注导出，并提供规则评估命令；必须人工查原文、去重、避免同一活动的版本跨开发集与留出集，再确认 100/50 的独立划分。不得把自动化样例或模型输出当成人工真值，也未宣称达到 98% / 85%。
2. **七天运行观察**尚在积累。应用会按周期采集并写入观察日志；另已安排本线程每日 10:00 检查，共七次。机器或应用未运行会影响采集，后续报告须说明实际跨度及缺失情况。
3. 六个受阻来源及部分附件需要继续修复或人工补充。首版以实际状态显示异常，不保证全国国央企的完整覆盖。
4. 扫描 PDF 与图片没有接入 OCR；复杂招聘、模糊年份、部分岗位延期和无法确定主体的内容会弃答或进入待核验。
5. 尚未对长期大规模数据和所有平台浏览器环境做性能验证。当前提供的是本地个人版本。
