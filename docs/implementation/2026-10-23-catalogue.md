# 官方名单随仓库建档

本轮落实“优先覆盖完整性”：新安装携带有明确官方出处的名单条目，按主体公开待接入招聘入口；网络受阻时仍可查询、补录和导出。全国完整覆盖仍未完成。

## 实现

迁移 0006 为名录快照添加来源元数据，保留取得方式、整理日期、发布日期、范围、完整性及说明。新建主体保留 unknown，不设置 verified_at 或名录 last_success。已存在企业的名称、别名、性质和人工记录不由摘录更新。相同内容按哈希复用，实时或人工版本始终优先，刷新失败保留名单及错误。

名录采集新增配置选择器的链接与编号正文适配，保留原表格适配；非表格适配不再扫描其他表格。湖南排除仅第一大股东身份的条目。当前配置是待本机直连复核的读取方式，最小数量校验失败保留已有快照；未对页面完整性作承诺。

全国覆盖页面与 API 展示整理方式、历史日期、范围、主管部门依据和未监测官网域名线索；CSV 同时导出性质核验状态及名单来源范围。全国总数、全国覆盖率继续返回 null。

## 验证与本机结果

132 项测试通过，包含全新初始化、重复启动、关闭自动载入、实时/人工版本优先、刷新失败保留、历史元数据、选择器范围及排除项；同时运行 lint、格式、JavaScript 语法与构建检查，wheel 包内包含名单和迁移。CI 使用固定数据，不访问外网。浏览器工具在当前 Work 设置中禁用，本轮未作浏览器视觉验收，页面通过服务接口与脚本静态检查。

迁移前备份到本机忽略目录；本机台账 249 个已知主体、219 个名单主体、8 个独立监测入口、28 项尚未取得名单。与备份逐表比较，1 条个人状态、7 条审核、226 条招聘、434 份文档、948 条截止声明和 2 条模型调用记录保持一致。本轮未调用模型。此处数字是本机快照，不能视为全国覆盖率。

下一批按缺口继续取得各省完整分页、地市区县/所属单位名单、当届独立校招入口。代理关闭后需重跑本机读取验证；程序不修改系统 VPN、代理分流或证书验证。
