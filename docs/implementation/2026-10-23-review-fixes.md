# 四阶段诊断修复计划

目标：人工审核可完成且有审计证据，同一公告重解析不分裂机会，错误日期不进入已核验列表，工作台优先展示近期信息，扩展结构化采集并报告真实覆盖。

1. 复现与保护数据：运行已有测试；备份数据库、附件及快照；停止旧服务后迁移。所有清理保留原始文档和人工状态，不永久删除历史。
2. 审核与存储：增加审核记录、附件人工转录和位置、发布日期补证、明确选择快照核验、冲突处理说明；保护人工确认/排除，按文档及招聘届别稳定关联；修复旧重复与孤儿关联，跨届机会独立。子公司关联需用户确认及关系依据。
3. 抽取与融合：收紧发布日期/日期/时间窗口；处理换行正文与隐藏噪音、通知与社招、公司名与工作地区；规范届别、季节、范围；模型弃答不被规则日期覆盖；24 点保持原文展示与精确时间并存。
4. 工作台：待核验按届别及新旧排序，归档倒序；单行排除与单源重试；统一“有内容、完整采集、待续跑、失败、有效校招”统计；非列表页面压缩重复概览。
5. 来源与配置：JSON 职位直接读取结构化元数据；逐一探测受阻来源的公开 HTML/API/浏览器入口，失败不计覆盖；初始配置只写个人覆盖项；导出标注集按活动分组，阻止同活动跨开发/留出集。
6. 验证与回放：新增最小回归样例并跑离线全套检查；从本地快照重新解析，记录清洗前后、合并与弃答数量；浏览器验证审核表单和视图，更新验收记录。真实站点访问受阻与人工标注、七天观察仍单独列出，不以目标数字代替实测。

技术约束：自动发布继续要求逐字可定位的原文；只有显式人工核验可以采用附件转录、人工年份依据和冲突说明，均需绑定文档并保存审核记录。不得仅凭集团官网域名自动认定子公司隶属关系。

## 实施与实测

- 审核和存储：新增迁移 0004 与独立审核表；图片/扫描件附件转录、年份补证、带说明的冲突消解、显式快照审核均有记录。原人工决定受到保护，原文变化会等待复核。集团关系需明确证据。
- 抽取和模型融合：修复跨段落款、日期/时段混淆、发布日期误取、空/懒加载图片；清洗企业尾部、明确地点与届别，排除系统通知及明确社招；模型弃答不再被规则日期覆盖；24 点按原文日期展示，底层保持精确时刻。
- 工作台：近期届别优先、往届折叠、归档倒序、行内排除、单源重试；来源页面不再占用大块 Hero。校招内容、已核验和待续跑分别计数，维护通知不计作有效校招来源。
- 采集和配置：NCSS 接收具体岗位标题、发布日期及结构化地点等字段，保存续跑的 API 元数据；增加可配置公开 POST JSON 读取、Nuxt 内嵌公告读取；联通 2027 届招聘海报已实际读取并留存 SHA256。新个人配置按覆盖项继承，标注导出分组并检测泄漏。
- 本地修复先备份，合并 7 条同届重复记录；首次离线检查 187 份文档、无解析异常，修复后有效机会均能找到保留的原文或截止证据。所有旧快照与人工状态保留，非招聘通知标记排除。
- 浏览器在独立临时数据库中完成了附件转录审核提交，显示“人工确认”及转录位置、说明、快照来源；没有向真实数据库添加合成已核验机会。真实工作台已检查排序、往届折叠和单源按钮。
- 最终离线回放 192 份文档，160 份判为非目标招聘、20 份仍需补证，解析异常为零；这些是文档处理数量，不是新增岗位或人工真值数量。
- 验证：107 项测试通过，Ruff 与 JavaScript 语法检查通过；独立目录从冻结锁文件安装，`init` / 无模型凭证 `doctor` 成功，数据库完成迁移 0004。构建成功，安装包包含迁移、审核页面及修复模块，不含个人数据与凭证。

## 扩源限制

本轮本机仍不能稳定读取国务院国资委、上海国资委、中国石油和中国石化；连接失败或 HTTP 412 已记录。电信取得过真实内容，但本轮详情仍异常。移动目前取得的是维护/公示公告，已排除，不能算有效校招源。

本轮可用状态为中行、国家能源、NCSS、联通四源（其中中行和 NCSS 尚待续跑）；累计五类来源取得过校招内容。不宣称达到八源覆盖或全国完整覆盖。

参考的官方入口：[国务院国资委招聘](https://wap.sasac.gov.cn/n2588035/n2588325/n2588350/index.html)、[上海国资委国企招聘](https://www.gzw.sh.gov.cn/shgzw_xxgk_cqzp/index.html)、[联通校园招聘](https://www.chinaunicom.com.cn/46/menu01/528/column06)、[中国石化招聘](https://job.sinopec.com/)。站点存在不等于本机采集可用，不能把搜索结果或失败入口计为成功覆盖。

150 份人工标注及七天观察继续按原要求单独验收；本轮回归样例和隔离界面测试不计入人工真值。
